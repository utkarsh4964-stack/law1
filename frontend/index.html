How it works

From raw case file to structured report

Four steps, all grounded in the documents you upload — nothing is invented that isn't traceable to a source.

01

Upload the case file

.txt, .md or .pdf. Each document is validated, SHA-256 hashed and logged to the chain of custody.

02

AI reads & organizes

Entities, dated events and factual claims are extracted from every document automatically.

03

Timeline, graph & conflicts

A chronological timeline, an evidence connection graph, and any contradictions across documents.

04

Structured report

A 12-section exportable Markdown report, ready to hand off — with a full audit trail behind it.

Built for the field, not just the demo

One workspace your whole investigating team can actually use

Investigators upload, reviewers verify, admins manage access — everyone works from the same case file instead of scattered folders, group chats and printed reports.

The part investigators actually ask for

Two documents disagree. The platform will not let that slide.

Every factual claim in the case file is compared against every other claim. Where two statements cannot both be true, the conflict is surfaced with its type, a confidence score and both source exhibits side by side.

  • Dates, amounts, roles and sequences checked across the whole vault — not one document at a time.
  • Flagged, never resolved. Deciding which claim is true stays with the investigator.
  • Findings export to Markdown and flow straight into the final case report.

What's inside

Built for the whole investigation, not one document

Every feature below is grounded in the case's own documents and framed as analysis, never as a verdict.

Secure Document Vault

Hash-verified uploads with version and confidentiality tracking, searchable and filterable by type.

Investigation Timeline

Chronological, evidence-linked events with automatic gap detection across 30+ day silences.

Connections graph

People, organizations and locations mapped — click any connection to see the evidence behind it.

Contradiction detection

Conflicting claims surfaced with a conflict type and confidence score — always flagged for human review.

Similar cases

Pattern matches against a reference case library, framed as similarity — never an outcome prediction.

Case chat

Case, Evidence and Legal Knowledge modes, with a Hindi toggle and hold-to-speak voice input.

Role-based access

Admin, Investigator, Reviewer and Viewer roles gate case creation, uploads and deletion server-side.

Audit trail

Every sensitive action on a case — who did it, what it was, and when — in one searchable log.

Exportable report

A structured 12-section Markdown case report, generated on demand and downloadable in one click.
